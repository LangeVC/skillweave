# Landscape Mapping

## Input Requirements
- **Domain**: The industry or problem domain
- **Project scope**: What part of the domain the project targets
- **Technology context**: Relevant technologies, platforms, or standards
- **Time horizon**: Current state vs. 1-3 year outlook

## Instructions

### Step 1: Domain Dimensions
Map the landscape across these dimensions:

| Dimension | Current State | Trend | Disruption Risk |
|-----------|---------------|-------|-----------------|
| Technology | Key platforms, tools, frameworks | Where it's heading | Potential disruptors |
| Market | Major players, segments, size | Growth/shrink rates | New entrants |
| Regulation | Compliance requirements | Changes on horizon | Deregulation or tightening |
| User Behavior | Adoption patterns | Shifts in expectations | Behavioral changes |
| Standards | Industry protocols | Emerging standards | Proprietary vs open |

### Step 2: Landscape Diagram (Text)
Describe the competitive landscape as a structured overview:

```
                   [Domain Name]
                   /    |    \
          [Segment A] [Segment B] [Segment C]
          /    |        |    |        |    \
    [Player1] [Player2] [Player3] [Player4] [Player5] [Player6]
```

For each player, note: position, strength, and strategic move.

### Step 3: Trend Analysis
Identify 3-5 key trends. For each:
1. **Trend**: What is happening
2. **Evidence**: Specific data points, events, or examples
3. **Impact**: How it affects the project opportunity
4. **Timeline**: When this trend becomes significant

Include concrete examples — company announcements, product launches, funding rounds, or research publications.

### Step 4: Positioning Recommendation
Based on the landscape, recommend:
- Where to position within the landscape
- What to avoid (crowded or commoditized areas)
- What partnerships or ecosystem plays to consider

### Step 5: Next Action
- **Target artifact**: Research Summary (`.skillweave/templates/discovery/research-summary.md`)
- **Suggested next step**: Refine positioning based on stakeholder input

## Output Format
Markdown document with domain dimensions table, text-based landscape diagram, per-trend analysis sections, and positioning recommendation with rationale.
