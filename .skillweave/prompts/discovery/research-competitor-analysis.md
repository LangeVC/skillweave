# Competitor Analysis

## Input Requirements
- **Product category**: What kind of product/service is being built
- **Target market**: Market segment or industry
- **Known competitors**: Any competitor names (optional, discovery mode otherwise)
- **Differentiation focus**: What aspects matter most (feature set, UX, pricing, etc.)

## Instructions

### Step 1: Competitor Identification
Identify 3-7 competitors across three tiers:
- **Direct**: Solve the same problem for the same audience
- **Indirect**: Solve a different problem for the same audience
- **Adjacent**: Solve the same problem differently

### Step 2: Comparison Matrix
For each competitor, capture:

| Attribute | Comp A | Comp B | Comp C | Our Product |
|-----------|--------|--------|--------|-------------|
| Target User | | | | |
| Key Features | | | | |
| Pricing Model | | | | |
| Strengths | | | | |
| Weaknesses | | | | |
| UX Quality (1-5) | | | | |
| Market Share | | | | |

### Step 3: Competitive Analysis
For each significant difference between competitors and our planned product:
1. **What they do differently**: Specific feature or approach
2. **Why it matters**: Impact on user outcomes
3. **Risk/Opportunity**: Whether this is a threat or gap to exploit

Include concrete evidence: quote reviews, cite pricing pages, reference feature lists.

### Step 4: Strategic Insights
- **White space**: What no competitor does well
- **Over-served area**: Where competitors over-engineer for most users
- **Entry point**: The minimum viable differentiator

### Step 5: Next Action
- **Target artifact**: Competitor Matrix (`.skillweave/templates/discovery/competitor-matrix.md`)
- **Suggested next step**: Validate competitive assumptions with market research

## Output Format
Markdown document with competitor summary table, detailed comparison matrix, per-competitor analysis sections (one per competitor), and strategic insights summary.
