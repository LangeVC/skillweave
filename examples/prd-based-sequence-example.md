```bash

```

- Too many tasks for single-pass execution
- Dependencies require proper sequencing
- Verification needs multi-level approach

- Duration < 8 hours (overnight threshold)
- Dependency graph manageable
- Risk level not critical

## Simple Mode Example

For comparison, here's what a **Simple Mode (REX-style)** sequence would look like for a smaller PRD (1-3 tasks):

### Simple PRD Example
```json
{
  "project": {"name": "Bug Fix: Login Error", "version": "1.0.0"},
  "tasks": [
    {
      "id": "BUG-001",
      "title": "Fix authentication token expiration bug",
      "description": "JWT tokens expiring prematurely due to timezone issue",
      "estimated_minutes": 30,
      "priority": "high",
      "dependencies": [],
      "type": "bug-fix"
    }
  ],
  "execution_recommendation": {
    "mode": "simple",
    "reason": "1 task, 30 minutes, no dependencies",
    "suggested_workflow": "rex-simple",
    "complexity_score": 15
  }
}
```

### Simple Mode Sequence
```yaml
metadata:
  mode: "simple"
  workflow: "rex-simple"
  max_revisions: 2

steps:
  - id: "plan"
    type: "analysis"
    task: "Analyze login error and create fix plan"
    outputs: ["root_cause_analysis.md", "fix_plan.md"]
    
  - id: "implement"
    type: "execution"
    task: "Implement fix based on plan"
    depends_on: ["plan"]
    outputs: ["code_changes", "fix_implementation.md"]
    
  - id: "review"
    type: "verification"
    task: "Test fix and verify resolution"
    depends_on: ["implement"]
    outputs: ["test_results.md", "verification_report.md"]
    
  - id: "complete"
    type: "finalization"
    task: "Finalize and document fix"
    depends_on: ["review"]
    outputs: ["final_fix", "documentation.md"]

revision_loop:
  enabled: true
  max_revisions: 2
  trigger_conditions: ["tests_failed", "acceptance_criteria_not_met"]
```

## Key Takeaways

1. **Complexity-Driven Workflows**: PromptChain automatically selects the right execution strategy based on PRD analysis
2. **REX vs Ralph Loop**: Simple tasks get lightweight execution, complex projects get full Ralph Loop benefits
3. **Parallel Optimization**: Identifies and exploits parallel execution opportunities
4. **Capability-Based Routing**: Agent-agnostic assignments focus on required capabilities
5. **Structured Verification**: Multi-level quality gates ensure production-ready output
6. **Memory Integration**: Knowledge accumulation for continuous improvement

This example demonstrates how SkillWeave transforms a PRD into an optimized execution plan, bridging the gap between planning and implementation with intelligence and efficiency.
