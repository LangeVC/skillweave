# Workflow Recommendation

Based on PRD analysis, the recommended workflow is **Ralph Loop Attended**.

## Rationale
- 35 tasks exceeds simple mode threshold (1-3 tasks)
- Estimated 288 hours of work requires structured execution
- Mix of infrastructure, feature, integration, and testing tasks
- Moderate dependencies with parallel opportunities across feature areas

## Suggested Execution Strategy
1. **Phase 1 - Risk Mode Override System**: Configuration schema, CLI integration, interactive mode selection
2. **Phase 2 - Intelligent Skill Detection Engine**: Prompt analysis, skill-intent mapping, parameter validation
3. **Phase 3 - Onboarding Flow System**: Interactive guidance, skill switching, user experience integration
4. **Phase 4 - Integration & Testing**: Core integration, performance optimization, comprehensive testing

## Checkpoints
Human checkpoints after each phase for review and approval, plus additional checkpoints after major subsystems (risk mode resolver, detection engine, onboarding controller).
