# Web Search Providers

## DuckDuckGo (default)
- Type: Free web + news search
- API Key: Not required
- Limits: Rate-limited, best effort
- Time ranges: m (month), w (week), y (year)
- Best for: General use, zero-config

## Serper
- Type: Google search results via Serper.dev
- API Key: SERPER_API_KEY env var
- Free tier: 2,500 queries/month
- Time ranges: Post-hoc date filtering
- Best for: Google-quality results

## Tavily
- Type: LLM-optimized search API
- API Key: TAVILY_API_KEY env var
- Features: Advanced search depth, content extraction
- Time ranges: Post-hoc date filtering
- Best for: AI-native search with rich content

## Brave
- Type: Privacy-focused web search
- API Key: BRAVE_API_KEY env var
- Free tier: 2,000 queries/month
- Time ranges: Page age information
- Best for: Privacy-conscious use cases
